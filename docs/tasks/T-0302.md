# T-0302 (WORKER-1, world/view lane) — render NPCs in the engine view

## Priority task — read first
AGENTS.md, docs/ARCHITECTURE.md, src/core/contracts/m3-contracts.md (esp. §8),
your own M2 view work (tests/view/*, src/features/engine/view/*).

## Context
M0-M2 committed and green. M3 "People": WORKER-3 is building the people:sim that
writes NPC positions into `state.maps[mapId].npcs[npcId] = { npcId, x, y, facing }`
and moves them every `time:tick`. Your job is to make those NPCs visible in the
Three.js scene: low-poly humanoids that walk, face and get rebuilt on map changes.

## Goal
Render every NPC present in the CURRENT map's `state.maps[currentMapId].npcs`.
The view ONLY reads sim state — never write, never move NPCs here.

## Files to create/modify (your lane only)
- src/features/engine/view/npcs.ts   # NEW: NpcView class (group of meshes +
  per-frame update + rebuild)
- src/features/engine/view/EngineView.ts  # MODIFY: instantiate NpcView, feed it
  current map + npcs each frame, rebuild on `player:warped`
- tests/view/npcs.test.ts            # NEW: pure helper tests

## Requirements
1. Procedural low-poly humanoid, no new assets: torso box, head box, legs/arms,
   all from a few primitives. Color from the content NPC def:
   `npcDef.baseProfile.color` (tunic) and `baseProfile.hairColor` (head), with
   sensible defaults when missing (no color -> warm grey/amber). Respect the
   existing view style (soft, stylized, cohesive palette).
2. Position: interpolate smoothly between the previous tick's position and the
   current one across the 10-min tick window (track last-prev positions in a
   view-only map, NOT in state). Scale: 1 in-game tile ~ the same unit as the
   player mesh uses in this codebase (match it).
3. Facing: orient a subtle "face" feature (e.g. nose plane or eye box, or slight
   offset) per `facing`; add a gentle up/down bob while the NPC is walking
   (position changed since last tick).
4. Rebuild, not patch: when `player:warped` fires or the map's npcs set changes,
   dispose the old group and build from the new map's npcs. Never leave NPCs from
   other maps behind.
5. Keep 60 FPS cheap: instanced/merged primitives, no per-frame allocations,
   no shadows on NPCs unless trivially free, cull with the existing scene.
6. Do not break: WASD/player mesh, camera, day/night, weather, village/farm
   visuals, F3 overlay, dev server on :5170.

## Acceptance

- Warp farm<->village: NPC set swaps correctly (village NPCs vanish from farm and

- NPCs lerp smoothly while walking and face the direction of travel.
