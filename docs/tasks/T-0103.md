# T-0103 — SimulationRunner adapter

**Lane:** WORKER-2 (Simulation)
**Depends on:** T-0001 (done)

## Goal

Wire the existing Core logic to the scene through a thin MonoBehaviour adapter,
with EditMode tests proving the split holds.

`EmberHollow.Core` is already ported and green: `Rng`, `EventBus`, `GameClock`,
`GameState`, `ContentDb`, `StateFactory`, `InventorySim`, `FarmingSim`. Build on
it; do not rewrite it.

## Do

1. Create `Assets/Scripts/Engine/SimulationRunner.cs` in an `EmberHollow.Runtime`
   assembly that owns the authoritative `GameState`, `EventBus` and `Rng`, and
   advances the fixed-timestep tick (10 in-game minutes per tick).
2. It must be **thin**: own the tick, own the state, and expose them. No gameplay
   logic in the MonoBehaviour. If a rule cannot be a function over state, it
   belongs in Core.
3. Wire `FarmingSim` to the bus so a `tool:use-requested` becomes a resolved
   action with its `tool:used` / `tool:failed` split intact.
4. Expose the runner as a scene object through the Editor-automation pattern so
   the farm scene has it from the start.
5. EditMode tests proving:
   - the runner's assembly **may** reference UnityEngine but the Core assembly
     does not, and Core still compiles with `noEngineReferences: true`;
   - a full in-game day can be advanced deterministically through the runner's
     public surface with identical results for a given seed;
   - a saved state survives a runner teardown and rebuild.
6. Replace the placeholder `SimTicker` harness in
   `Assets/Tests/PlayMode/` with the real runner, so the PlayMode suite exercises
   shipped code rather than a test-only copy.

## Do not

- Put gameplay logic in a MonoBehaviour.
- Add a `UnityEngine` reference to `EmberHollow.Core`.
- Commit.

## Accept when

- `Assets/Scripts/Engine/SimulationRunner.cs` exists in an assembly that
  references `EmberHollow.Core`, and `EmberHollow.Core` still has
  `"noEngineReferences": true`.
- PlayMode tests drive the real runner over real frames.
- `scripts/run-tests.ps1` green in both tiers, with real counts.
- The report states the `-executeMethod` invocation for anything built by script.
