## 1. Shop sim (new src/features/shop/sim/ShopSim.ts, register id 'shop:sim')
- Extension state `state.extensions.shop = { stock: Record<shopId,
  Record<itemId, number>> }` (lazily initialized; infinite items have no entry).
- `shop:buy` `{ shopId, itemId, qty }`: resolve shop + entry + item; effective
  price = entry.price ?? item.price.buy; check shopping list for daily stock
  limits; check money; add stacks to inventory (inventory sim API for merging +
  first-empty-slot); decrement daily stock; emit `shop:bought`; on any failure
  emit `shop:denied` `{ reason: 'funds'|'space'|'stock', shopId, itemId }` and
  return unchanged state (exactly one of bought/denied).
- `shop:sell` `{ shopId, itemId, qty }`: only if shop.buys; remove qty of item
  from inventory; add `item.price.base * qty` money; emit `shop:sold`.
- `shop:restock`: restore daily stock counters to content qty each morning —
  hook this into your existing day-rollover pass (the same time:tick reducer
  that runs crop rollover/weather). Any checks must be deterministic and
  JSON-safe.
- Register the module in a src/features/shop/index.ts with
  `registerFeature(shopSim)` (id 'shop:sim'). WORKER-3 separately owns
  src/features/shop-ui/ for the shop dialog — do not create files there or in
  src/features/shop/ui*. This index registers ONLY shop:sim.
