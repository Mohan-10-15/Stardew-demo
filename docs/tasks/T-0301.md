## Contract summary (read the full m3-contracts.md, this is the pocket version)
- NPC positions live in `state.maps[mapId].npcs[npcId] = { npcId, x, y, facing }`;
  intents in `state.extensions.people.targets[npcId] = { mapId, x, y }`.
- Clock: `clockToGameMinutes(clock)` = 600 (6 AM) .. 2600 (2 AM) from
  src/core/time.ts; `dayIndex`, `dayOfWeek` (0=Sunday), `dayOfWeekName`.
- `resolveSchedule(def, { seasonIndex, weather, dayOfMonth, dayOfWeek, gameMinutes })`
  -> first matching override (missing field = wildcard) else `default`; then the
  LAST rule with from <= gm < to; no rule -> home (homeAnchor or map spawn).
- Movement: same map = walk tile-by-tile (deterministic A* over legend-walkable
  tiles; neighbors examined N, S, W, E in that order, lower f-cost wins; move up
  to NPC_WALK_TILES_PER_TICK = 3 tiles per 10-min tick; blocked by the player's
  tile and other NPCs; facing per step; stop at goal facing down). Different map
  = instant placement on the target tile (remove from old map, add to new).
- Dialogue: `pickDialogue(def, { hearts, weather, seasonIndex, gameMinutes,
  giftJustGiven }, rng)` -> byHeart (highest qualifying tier) > weather >
  season > time (morning <1200, day 1200..<1800, evening 1800..<2400, night
  >=2400) > default; when giftJustGiven use giftReply by taste. In-pool pick via
  `rng.fork('dialogue:' + npcId + '@' + dayCount)`.
- Emits: `dialogue:show { npcId, lines }`, `friendship:changed { npcId, hearts,
  delta, taste }`. Taste values: 'loved'|'liked'|'neutral'|'disliked'|'hates'.
- Interact routing: when `player:interact` targets a tile with an NPC adjacent,
  no held item -> people:talk; held item -> people:gift. Wire this in your UI/input
  layer (you own input:ui) OR reduce on the existing player:interact path — pick
  whichever the engine/input loop already dispatches and document your choice in
  the report. Gifting consumes 1 of the item.

## Acceptance
- Schedule: an NPC is on different tiles at 09:00 (900), 13:00 (1300), 19:00 (1900).
- Dialogue differs for rain vs sun and for low vs high friendship hearts.
- A loved gift and a hated gift move hearts in opposite directions, and the reply
  line differs. Only the first gift of a day counts.
- Talking once per day gives +0.25 hearts, emitting friendship:changed.
- The dev build still boots; the dialogue overlay opens when you talk to an NPC.
