## 1. End-of-day summary dialog (after sleep / pass-out)
- WORKER-2 will emit `day:summary` on the bus with:
  `{ dayCount, date:{year,seasonIndex,dayOfMonth}, weather, forecast,
  goldEarned, itemsSold:{itemId,qty,gold}[], cropsHarvested:{cropId,qty}[],
  collectedForage:{itemId,qty}[], xpEarned:{skill,amount}[] }`.
- Build a `summary` feature module (lane 'ui', id 'summary:ui', self-registered
  in src/features/summary/index.ts): ui() returns { mount(root), dispose() }.
  It subscribes to `day:summary` and shows a modal dialog (reuse ui-kit dialog
  primitive) titled "Day complete" (i18n) listing: date, weather,
  goldEarned, then three sections (Shipping, Harvest, Forage) with item names
  resolved via ctx.content.items + qty + gold, and an experience section. A
  close button dismisses (dispose/hide). Must also render when content map is
  empty (guard). Guard for no-document headless: mount() no-ops without DOM.
- All strings in src/features/ui-kit/i18n/en.ts (add keys; keep the i18n table
  complete — no hardcoded display strings).
