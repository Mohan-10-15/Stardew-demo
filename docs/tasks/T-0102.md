# T-0102 — Walkable farm scene with Cinemachine follow

**Lane:** WORKER-1 (World & Engine)
**Depends on:** T-0101

## Goal

One walkable, lit farm scene built entirely from imported prefabs, with an
angled third-person Cinemachine follow camera.

## Do

1. An Editor script that builds `Assets/Scenes/Farm.unity` end to end in code.
2. Ground and environment from the imported Quaternius prefabs, **not**
   `CreatePrimitive` cubes.
3. Farm buildings and props placed from the imported prefabs.
4. Lighting for the season: directional sun with shadows, ambient, and fog. Add
   a `DayNightController` MonoBehaviour that can drive sun angle, colour
   temperature and ambient from the in-game clock. It reads state and reflects it
   into transforms and lights — no gameplay logic in the MonoBehaviour.
5. A Cinemachine camera doing an angled third-person follow on a player rig built
   from a KayKit character prefab, with collision handling so the camera does not
   clip terrain.
6. The farm must be **walkable with continuous 8-directional movement** — no
   tile-lock. Movement is a thin MonoBehaviour calling into POCO logic.

## Do not

- Place anything by hand in the Editor.
- Commit.

## Accept when

- `Assets/Scenes/Farm.unity` exists on disk, written by script.
- The scene contains a lit farm with a KayKit character, a following camera, and
  no missing (magenta) materials.
- The report states the `-executeMethod` invocation.
- `scripts/run-tests.ps1` green in both tiers, with real counts.
- A WebGL `BuildPipeline.BuildPlayer` succeeds.
