## Context
Ember Hollow: DOM/CSS overlay UI over a Three.js canvas. UI modules read
store.state and dispatch sim actions; they never mutate sim state. Strings are
data (i18n-ready). This task = the M1 UI foundation: a reusable kit, the HUD,
and an input mapping module; input goes to the engine sim via dispatch.

## Goals
1. `src/features/ui-kit/` — reusable DOM primitives (panel, button, slider,
   tooltip, tab, dialog, icon) with CSS in src/features/ui-kit/ui-kit.css, all
   strings in i18n tables. Export `createUiKit()` returning component factory
   functions bound to a container. Must be headless-safe: no DOM at import time;
   mounting only when called.
2. `src/features/hud/` — HUD: date/season, clock, weather, money, energy + health
   bars, hotbar with selected-slot ring, tooltip on hover of hotbar slots, and a
   shipping-box count. All update from `state:changed`. Dispatch select/move via
   store for hotbar interactions (drag/drop basic swap ok to implement now).
3. `src/features/input/` — input mapping module: keyboard (WASD/arrows move,
   Space/E interact, 1-9 hotbar select, I drag mode target later, M map later)
   + mouse (click interact, wheel handled by engine zoom). Keys arrive as
   dispatch: `player:move` {dx,dy}, `player:interact`, `player:select-slot`;
   also forward wheel + raw events the engine needs. Mapping table lives in data
   (src/features/input/keymap.ts) with default bindings — remapping UI comes in
   M7, keep the structure data-driven now.
4. All M1 UI strings in a JSON/TS i18n table (src/features/ui-kit/i18n/en.ts).
5. Wire-up: each feature module exposes `ui(){ return { mount(root), dispose() } }`.
   core's mountDomModules already mounts `.ui()` handles into #ui-root; ensure
   your modules mount themselves there and clean up on dispose.

## Contract notes
- Actions table + placed-object vocab in m1-contracts.md (dispatch only).
- HUD energy: `player.energy`, `player.energyMax`, `player.health`.
- Money: `player.money`. Clock: `world.clock.hour:minute` (24h, midnight-relative;
   display "6:00 AM"-style or "06:00" — pick one, keep in i18n).
- Date: `world.calendar.year/seasonIndex/dayOfMonth`; seasons
  SEASON_NAMES=['Spring','Summer','Fall','Winter'].
- Weather: `world.weather` ∈ sun|rain|storm|snow|wind.
- Hotbar = `player.inventory.slots` (array, null = empty), selected =
  `player.inventory.selected`.
- Tooltips show item name + description + qty — resolve ids via
  ctx.content.items.get(id) passed into the HUD on setup. If content is empty in
  tests, guard.
