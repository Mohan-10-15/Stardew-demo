# T-0106 — Pixel font, shipping bin + money panels, sleep payout

**Lanes:** WORKER-1 (engine/scene), WORKER-2 (Core sim), WORKER-3 (UI)
**Depends on:** T-0103, T-0104, T-0105 (all done)
**Status:** code complete; Unity verification blocked (D-0022)

## Goal

Finish the M0 UI task and open the M1 economy loop: a real CC0 pixel font, a
shipping bin the player can actually use, a visible wallet, and a sleep action
that pays the bin out and rolls the day.

## Contract

- `GameState.Player.ShippingBin` is a list of `ItemStack`, deep-copied on clone.
- `ShippingSim.Deposit` removes sellable items from the bag atomically and emits
  `ShippingDeposited` on success or `ShippingBlocked` on failure. Quality is
  preserved; tools and unknown ids are refused.
- `ShippingSim.Collect` pays the whole bin at sleep: base SellPrice times
  100/125/150% for normal/silver/gold, rounded down. It emits `ShippingSold`
  and `MoneyChanged`; an empty bin is a distinct `ShippingBlocked` failure.
- `SleepSim.Sleep` collects only a non-empty bin, advances to the next 06:00,
  runs `DailyTick`, restores energy and health, emits one `DaySummary`, then
  clears `day:` counters.
- Entering sleep is gated on proximity to a `BedStation` in the scene; the
  refusal publishes `SleepBlocked { Reason = "no-bed" }`.

## Acceptance

- EditMode and PlayMode green with real counts, and WebGL builds, once a Unity

  `EmberHollow.EditorTools.FarmSceneBuilder.Build` so the bed and crate exist.
