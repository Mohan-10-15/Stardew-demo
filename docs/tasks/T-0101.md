# T-0101 — Import the first CC0 art packs

**Lane:** WORKER-1 (World & Engine)
**Depends on:** T-0001 (done)

## Goal

Set the visual foundation from the very first commit, so nothing is ever built on
blocky primitives and nothing has to be retrofitted later.

## Do

1. Download **one KayKit character pack** (rigged + animated characters) from
   `kaylousberg.itch.io`.
2. Download **one Quaternius farm pack** (Farm Buildings, Nature, or Farm
   Animals) from `quaternius.itch.io`.
3. Import the `.fbx` / `.glb` files into `Assets/Art/kaykit/` and
   `Assets/Art/quaternius/`.
4. Verify each imported model has correct scale, a sensible pivot at the feet, and
   no missing materials or textures.
5. Build prefabs under `Assets/Prefabs/` — one per imported character and prop —
   using `PrefabUtility.SaveAsPrefabAsset`.
6. Add both packs to `docs/ASSET_LICENSES.md` with source URL and license.

## Do not

- Download anything outside KayKit, Quaternius and Kenney.nl. Cohesion beats
  per-asset fidelity.
- Place models in a scene by hand.
- Commit, reset, stash or checkout.

## Accept when

- `Assets/Art/kaykit/` and `Assets/Art/quaternius/` contain imported models.
- `Assets/Prefabs/` contains prefabs written by script.
- `docs/ASSET_LICENSES.md` lists both packs with source URLs.
- The report states the exact `-executeMethod` invocation used.
- `scripts/run-tests.ps1` is green in both tiers with real counts.
