## The eight-input core loop

| Action | Keyboard / mouse | Gamepad |
| --- | --- | --- |
| Move | W A S D / arrows | Left stick |
| Look | Mouse | Right stick |
| Jump | Space | A |
| Interact | E | X |
| Use held item | Left click | RT |
| Alt-use / place / cancel | Right click | LT |
| Hotbar | 1-9 / wheel | D-pad left / right |
| Menu / back | Esc / B | Start / B |

K stays a keyboard attack alias; V switches camera; Tab or I opens
the inventory; J opens the journal. Esc or B always backs out, Enter,
E or A always confirms, and every menu works by mouse, keyboard and
gamepad focus.
